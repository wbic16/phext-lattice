# wikibench results

Generated by `bench/wiki/run_all.sh`. Corpus: `wikipedia_en_climate_change_mini_2024-06.zim` (Kiwix, openzim/zim-testing-suite), lead-section text. Scale N replicates the corpus N× with suffixed titles. Latencies are p50 (p99) per operation; ZIM numbers come from python-libzim (C++), everything else from Rust — see the Python calibration row.
