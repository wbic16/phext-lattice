Level editor

One map, many layers. Every layer is one scroll of plain text.

—
The whole level is one tiny text file — a phext. Each layer is one scroll: the map drawn as plain text, one line per row, a space where a square is empty. Open the file in any text editor and you can read every layer as a picture. The kit zip has the level plus tiny reader/writers for Python, Rust, Node, browser JS, and C. Take the starting file here: ascii-map.phext (314 bytes). A free example, built for a game maker who needed more room inside each square of an ASCII map. No sign-in, no ads, ever.
