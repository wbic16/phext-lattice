Level editor

One map, many layers. Every square holds one letter per layer.

—
The whole level is one tiny text file — a phext. Addresses are three numbers: down · layer · across. Take the starting file here: ascii-map.phext (255 bytes). A free example, built for a game maker who needed more room inside each square of an ASCII map. No sign-in, no ads, ever.
