One map, drawn three times

This is a map from a game. One map is not enough: a square can hold the ground, a thing standing on it, and a story about what happened there — all at once. So the map is drawn three times, once per section. Each section is one kind of thing. And every square, in every section, is still just one letter.

Tap any square in any section to read it.

Pick a square

Section 1 is the ground. Section 2 is things. Section 3 is what happened. The chest is in section 2, across 10, down 3.

Three numbers find any letter

Every letter lives at an address of three numbers: down · section · across. The chest is down 3, section 2, across 10 — address 3 · 2 · 10, and its letter is c. That is the whole trick. Phext can carry nine numbers; this map needs three, so it uses three.

Set a letter yourself

Tap a square in any section, type one letter, and set it. One letter is all a square ever holds — that rule is what keeps the map simple.

Add a whole section

Take the file

The whole map — all three sections, every letter — is one tiny text file: ascii-map.phext (255 bytes). Open it in any text editor. It is a phext: plain text with addresses, nothing hidden. Change a letter, and the map changes.
